# Veritas AI

**An Enterprise Multi-Agent Knowledge & Compliance Intelligence Platform.**

Built for the "Deploy or Die" Hackathon (Track C: Knowledge & Compliance Agents).

## Overview
Veritas AI is a true Multi-Agent AI System. It is not a standard RAG chatbot. Instead, it utilizes a sophisticated pipeline of specialized AI agents working in concert to process documents, retrieve knowledge, reason over facts, rigorously validate citations, and audit for compliance and risk.

## Features
- **Zero Hallucination Guarantee**: Strict citation validation ensures every claim is backed by highlighted evidence.
- **Multi-Agent Pipeline**: Real-time visualization of data flowing between the Knowledge, Reasoning, Citation, Compliance, and Risk agents.
- **Enterprise UI**: Premium dark mode design with glassmorphism, Aurora gradients, and Framer Motion animations.

## Tech Stack
- **Frontend**: React, Vite, TypeScript, Tailwind CSS, Framer Motion
- **Backend**: Python, FastAPI
- **AI & RAG**: Google Gemini API, PyMuPDF, ChromaDB
